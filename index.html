Smart Sorting Trash Can

Automated waste classification using AI, hardware, and engineering design

About the Project

The Smart Sorting Trash Can is an interdisciplinary engineering project designed to reduce recycling contamination by automatically identifying and sorting waste. Using a Raspberry Pi, camera module, and machine learning model, the system classifies items and directs them into the correct bin using a servo mechanism.

System Workflow

  1. Object detected using IR sensor
  2. Camera captures image
  3. Image sent to ML model (ResNet50)
  4. Classification: trash vs recycling
  5. Servo tilts platform to correct bin

Engineering Breakdown

Mechanical

Tilting platform and bin design for sorting items.

Electrical

Raspberry Pi, sensors, and servo motor integration.

Software

Flask server and image classification using machine learning.

Chemical Engineering

Odor reduction system using chemical spray design.
